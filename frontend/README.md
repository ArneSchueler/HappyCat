🐱 HappyCat – World Happiness Data Center
Note: This is an educational project developed during a 1-week training intensive. It is a proof-of-concept for data visualization and modern frontend layouts, not a commercial application.

📌 Project Overview
HappyCat is a data-driven dashboard designed for the fictional editorial team Health & Society News. The application aims to make global societal developments—specifically the World Happiness Index—accessible and interactive for everyday readers.

🖼️ Dashboard Layout
The frontend follows a strict 2-column grid system (2fr 1fr) to maintain a clean and scannable interface:

Column 1: Analysis & Comparison (2fr)
Happiness Trends: An interactive line chart displaying "Life Satisfaction Over Time" (2010–2024). Users can toggle variables like GDP per Capita, Social Support, and Healthy Life Expectancy.

Country Comparison: A dedicated section to compare two specific nations, highlighting "Top Gainers," "Biggest Declines," and regional insights.

Column 2: Rankings & News (1fr)
Country Rankings: A live leaderboard of the current World Happiness scores, with quick-filter options for different continents (Europe, Asia, Africa, Americas).

Happy News of the Day: A sidebar dedicated to positive news stories (e.g., Bhutan's Gross National Happiness milestones) to balance the data-heavy analysis with uplifting content.

🎨 Design System
The UI is built around the HappyCat branding:

Colors: A palette of Vibrant Orange for data highlights and Teal/Dark Navy for professional structure.

Assets: The logo (image_aa155d.jpg) is used as the primary brand mark to create a friendly, approachable user experience.
